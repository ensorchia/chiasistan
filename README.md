# Chiasistan - Bilgisayar Asistanı ve Uygulama Yükleyici

Chiasistan, Windows işletim sistemi için geliştirilmiş bir bilgisayar asistanı ve uygulama yükleyici uygulamasıdır. Bu uygulama ile:

- Popüler tarayıcıları (Chrome, Brave, Opera GX, Firefox)
- Oyun başlatıcılarını (Steam, Epic Games, EA App, Ubisoft Connect)
- Yazılım araçlarını (Visual Studio Code, Visual Studio 2022)
- Sistem araçlarını (Microsoft Edge kaldırma, bilgisayar optimizasyonu, driver güncelleme)

kolayca yükleyebilir ve yönetebilirsiniz.

## Kurulum

1. Python 3.8 veya üstü sürümünün yüklü olduğundan emin olun
2. Gerekli kütüphaneleri yükleyin:
   ```
   pip install -r kutuphaneler.txt
   ```
3. Uygulamayı çalıştırın:
   ```
   python chiasistan.py
   ```

## Özellikler

- Renkli ve kullanıcı dostu arayüz
- İndirme işlemlerinde ilerleme çubuğu
- Kategorize edilmiş uygulama listesi
- Sistem optimizasyon araçları
- Otomatik driver güncelleme kontrolü

## Gereksinimler

- Windows işletim sistemi
- Python 3.8+
- İnternet bağlantısı
- Yönetici izinleri (bazı sistem işlemleri için)

## Not

Bazı sistem işlemleri için yönetici izinleri gerekebilir. Uygulamayı yönetici olarak çalıştırmanız önerilir.
